How the estimate works

    
Before: wakes a day × tokens per wake. Method 1: the same with the new interval. Method 2: a deterministic check runs on every wake at 0 tokens and calls the model only when something changed. A longer interval makes a change more likely per wake, so the share becomes 1 − (1 − changed)new / old. The same formula is in demo/heartbeat_model.py, which you can run on your own fleet file.
